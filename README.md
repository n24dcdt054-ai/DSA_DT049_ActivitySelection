# DSA_DT049_ActivitySelection - Đồ án Bài toán Chọn hoạt động

## 1. Giới thiệu
Đồ án cài đặt thuật toán Tham ăn (Greedy Algorithm) giải quyết bài toán Chọn hoạt động (Activity Selection Problem - Mã đề DT049).

## 2. Cấu trúc mã nguồn
- main.py: Mã nguồn chính thực thi thuật toán và chạy bộ kiểm thử 12 ca (TC01-TC12).
- README.md: Tài liệu hướng dẫn cài đặt và thực thi.
- .gitignore: Tệp cấu hình bỏ qua tệp tạm.

## 3. Yêu cầu môi trường
- Ngôn ngữ: Python 3.8+
- Thư viện: Sử dụng thư viện tiêu chuẩn của Python (sys, time).
